# Superseded engine releases

The following `dotfiles-provision` engine tags are **immutable mistakes**. They
exist because tags are never moved or deleted, but they are **not usable
releases** and must not be pinned or deployed:

- `v0.1.54`
- `v0.1.55`

`v0.1.56` and every later release (including the authoritative `v0.1.64`) are
the correct engine tags. Consumers must pin `v0.1.56+`/`v0.1.64`, never
`v0.1.54` or `v0.1.55`.

This note is documentation only; it does not change the tags themselves.
